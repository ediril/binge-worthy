# Overview

This project is to build a site like Netflix, but for binge-worthy, "high-fiber", good-for-your-brain, intellectually-stimulating edutainment videos, covering tech, business, coding, science, AI, etc.

It isn't meant to be explicitly for learning, but rather to find good-for-you content to watch
instead of binge watching Netflix shows that rot the brain.
